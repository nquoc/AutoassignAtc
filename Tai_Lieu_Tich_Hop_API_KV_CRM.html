1. TỔNG QUAN HỆ THỐNG & KIẾN TRÚC XÁC THỰC (AUTHENTICATION & SECURITY)

Hệ thống KiotViet CRM được xây dựng trên nền tảng VTiger CRM Framework. Mọi tác vụ trao đổi dữ liệu HTTP với máy chủ bắt buộc phải trải qua 2 lớp bảo mật song song:

  1. Session Cookie (PHPSESSID): Lưu trữ phiên đăng nhập được cấp sau khi gửi form Auth tại index.php?module=Users&action=Login.
  2. CSRF Magic Token (__vtrftk): Mã Token ngẫu nhiên chống giả mạo request thay đổi liên tục theo từng giao dịch và phiên truy cập.
⚠️ QUY TẮC AN TOÀN TUYỆT ĐỐI: Không bao giờ hardcode giá trị Token __vtrftk cố định. Trước khi gửi các lệnh POST làm thay đổi dữ liệu, hệ thống tự động phải thực hiện 1 request GET siêu nhẹ để trích xuất mã Token tươi mới nhất.

🔑 Thuật toán bóc tách CSRF Token bằng Python Regex:

import re
import urllib.request

def fetch_csrf_token(cookie_str, module="HelpDesk", record_id=None):
    if record_id:
        url = f"https://kvcrm.kiotviet.vn/index.php?module={module}&view=Detail&record={record_id}"
    else:
        url = f"https://kvcrm.kiotviet.vn/index.php?module={module}&view=List"
    
    headers = {"cookie": cookie_str, "user-agent": "Mozilla/5.0"}
    req = urllib.request.Request(url, headers=headers)
    with urllib.request.urlopen(req, timeout=8) as resp:
        html = resp.read().decode('utf-8', errors='ignore')
    
    match = re.search(r'csrfMagicToken\s*=\s*["']([^"']+)["']', html)          or re.search(r'name=["']__vtrftk["']\s+value=["']([^"']+)["']', html)          or re.search(r'(sid:[a-zA-Z0-9,]+)', html)
    
    return match.group(1) if match else None

2. API 1: CHUYỂN NGƯỜI XỬ LÝ (CHANGE OWNER ACTION)

Chức năng: Gán hoặc chuyển giao Ticket HelpDesk hoặc Đơn CSKHSC cho nhân viên / nhóm làm việc mới.

  • HTTP Method: POST
  • Endpoint: https://kvcrm.kiotviet.vn/index.php
  • Content-Type: application/x-www-form-urlencoded
  • Header yêu cầu: X-Requested-With: XMLHttpRequest

Danh sách Tham số Body (Form Data):

Tham số Kiểu dữ liệu Trạng thái Mô tả chi tiết
__vtrftk String Bắt buộc Mã CSRF token bóc tách từ HTML
module String Bắt buộc HelpDesk (Ticket) hoặc CSKHSC (Đơn ATC)
action String Bắt buộc Cố định: ChangeOwnerAction
viewname String Bắt buộc 19320 (với HelpDesk) hoặc 16309 (với CSKHSC)
changeOwnerId String Bắt buộc Mã ID Nội bộ CRM của nhân viên nhận (Ví dụ: 12147 cho NV 8466)
selected_ids[] String / Array Bắt buộc Record ID của bản ghi muốn chuyển (Ví dụ: 106725000)
excluded_ids[] String Tùy chọn Mặc định truyền chuỗi rỗng ""
search_params String Tùy chọn Mặc định truyền [[]]

Phản hồi JSON Mẫu:

{
  "success": true,
  "result": {
    "flag": true,
    "message": "Assigned Owner Changed Successfully"
  }
}

Chức năng: Đổi loại công việc của đơn CSKHSC sang chế độ Hỗ trợ Online (tương ứng thao tác nút Chuyển Online trên giao diện).

  • HTTP Method: GET / POST
  • Endpoint: https://kvcrm.kiotviet.vn/index.php

Danh sách Query Parameters:

Parameter Mẫu giá trị Mô tả
module CSKHSC Module Đơn hỗ trợ gian hàng
action SwitchOnlineSupport Action chuyển Online
record 105251250 Record ID của đơn CSKHSC
cskhcs_type CSKHOI_DVKH Mã loại hỗ trợ Online (xem danh mục bên dưới)

Danh mục Mã cskhcs_type Hợp lệ:

4. API 3: CẬP NHẬT TRƯỜNG THÔNG TIN AJAX (SAVEAJAX FIELD UPDATE)

Chức năng: Đổi trạng thái xử lý, cập nhật lý do từ chối hoặc chỉnh sửa mô tả nhanh mà không cần tải lại toàn bộ bản ghi.

  • HTTP Method: POST
  • Endpoint: https://kvcrm.kiotviet.vn/index.php

Request Parameters (Form Data):

Parameter Type Description / Value
__vtrftk String Mã CSRF token bảo mật
module String HelpDesk hoặc CSKHSC
action String Cố định: SaveAjax
record String Record ID của Ticket hoặc Đơn CSKHSC
field String Tên trường cần thay đổi (ticketstatus, ticketdenyreason, cskhcs_status, description)
value String Giá trị mới cần ghi đè vào hệ thống

Trường Hợp Đặc Biệt: Từ Chối Ticket HelpDesk

📌 Quy trình bắt buộc khi Reject Ticket: Bắt buộc phải thực hiện 2 request SaveAjax liên tiếp:
  1. Gửi field="ticketdenyreason", value="Không thuộc phạm vi dịch vụ".
  2. Gửi field="ticketstatus", value="Rejected".

7. API 6: TÌM KIẾM TỔNG HỢP TOÀN HỆ THỐNG (GLOBAL SEARCH / BASIC AJAX SEARCH)

Chức năng: Tra cứu nhanh Ticket, Retailer ID, Lead, Hợp đồng hoặc Serial phần cứng theo mã gian hàng (Domain) hoặc từ khóa bất kỳ trên toàn bộ hệ thống CRM hoặc lọc riêng theo từng phân hệ.

  • HTTP Method: GET
  • Endpoint: https://kvcrm.kiotviet.vn/index.php?module=Vtiger&view=BasicAjax&mode=showSearchResults&value={QUERY}
  • Header yêu cầu: X-Requested-With: XMLHttpRequest

Danh sách Tham số Query:

Tham số Kiểu dữ liệu Trạng thái Mô tả chi tiết & Tùy chọn
module String Bắt buộc Cố định: Vtiger
view String Bắt buộc Cố định: BasicAjax
mode String Bắt buộc Cố định: showSearchResults
value String Bắt buộc Từ khóa tìm kiếm (Ví dụ: nhanongcafe, TT8821066, 501162149)
searchModule String Tùy chọn Phân hệ cần tìm kiếm riêng biệt:
  • HelpDesk: Chỉ tìm riêng trong Tickets (Phiếu hỗ trợ)
  • Serial_Product: Chỉ tìm riêng trong Serial phần cứng
  • CSKHSC: Chỉ tìm riêng trong CSKH SC (Đơn hỗ trợ)
  • (Bỏ trống hoặc không truyền): Tìm kiếm toàn bộ hệ thống (All Records)

Code Mẫu Python Tìm Kiếm Ticket Hoặc Toàn Hệ Thống:

import urllib.parse, urllib.request, re, html

def search_crm_records(query, module_filter="HelpDesk", cookie_str=""):
    url = f"https://kvcrm.kiotviet.vn/index.php?module=Vtiger&view=BasicAjax&mode=showSearchResults&value={urllib.parse.quote(query)}"
    if module_filter:
        url += f"&searchModule={module_filter}"
    
    headers = {
        "cookie": cookie_str,
        "user-agent": "Mozilla/5.0",
        "x-requested-with": "XMLHttpRequest"
    }
    
    req = urllib.request.Request(url, headers=headers)
    with urllib.request.urlopen(req, timeout=10) as resp:
        res_html = resp.read().decode('utf-8', errors='ignore')
    
    # Bóc tách danh sách record ID tìm thấy
    results = []
    rows = re.findall(r'<tr[^>]*data-crmid=["\'](\d+)["\'][^>]*id=["\'](\w+)_globalSearch_row_\d+["\'][^>]*>(.*?)</tr>', res_html, re.DOTALL)
    for crm_id, mod_name, row_content in rows:
        clean_text = html.unescape(re.sub(r'<[^>]+>', ' ', row_content).strip())
        results.append({
            "record_id": crm_id,
            "module": mod_name,
            "summary": re.sub(r'\s+', ' ', clean_text)
        })
    return results

9. BẢNG MÃ LỖI THƯỜNG GẶP (ERROR CODES & TROUBLESHOOTING)

Mã Lỗi / Response Nguyên nhân Giải pháp khắc phục
{"success":false,"error":{"code":"Bạn không có quyền thực hiện thao tác này"}} Bản ghi đã bị khóa, thuộc tài khoản khác hoặc tài khoản CRM hiện tại không có quyền sửa bản ghi này. Chỉ thực hiện thêm bình luận (ModComments) hoặc liên hệ Admin phân lại quyền phân bổ bản ghi.

Read operation timed out Request xử lý quá nhiều bản ghi cùng lúc dẫn tới timeout mạng. Chuyển từ Mass Action sang xử lý vòng lặp đơn từng bản ghi với timeout >= 10s.

10. CODE MẪU PYTHON PRODUCTION READY (CLASS HOÀN CHỈNH)

import urllib.request, urllib.parse, json, re

class KVCrmClient:
    def __init__(self, cookie_str):
        self.cookie_str = cookie_str
        self.base_url = "https://kvcrm.kiotviet.vn/index.php"
        self.headers = {
            "content-type": "application/x-www-form-urlencoded",
            "cookie": self.cookie_str,
            "user-agent": "Mozilla/5.0",
            "x-requested-with": "XMLHttpRequest"
        }

    def get_csrf_token(self, module="HelpDesk", record_id=None):
        url = f"{self.base_url}?module={module}&view=Detail&record={record_id}" if record_id else f"{self.base_url}?module={module}&view=List"
        req = urllib.request.Request(url, headers={"cookie": self.cookie_str})
        with urllib.request.urlopen(req) as resp:
            html = resp.read().decode('utf-8', errors='ignore')
        match = re.search(r'csrfMagicToken\s*=\s*["']([^"']+)["']', html) or re.search(r'name=["']__vtrftk["']\s+value=["']([^"']+)["']', html)
        return match.group(1) if match else None

    def change_owner(self, module, record_id, target_staff_id, viewname="19320"):
        token = self.get_csrf_token(module, record_id)
        form = [
            ("__vtrftk", token), ("module", module), ("action", "ChangeOwnerAction"),
            ("viewname", viewname), ("excluded_ids[]", ""), ("changeOwnerId", str(target_staff_id)),
            ("search_params", "[[]]"), ("selected_ids[]", str(record_id))
        ]
        data = urllib.parse.urlencode(form).encode('utf-8')
        req = urllib.request.Request(self.base_url, data=data, headers=self.headers)
        with urllib.request.urlopen(req) as resp:
            return json.loads(resp.read().decode('utf-8'))

    def switch_online_support(self, record_id, support_type="CSKHOI_DVKH"):
        url = f"{self.base_url}?module=CSKHSC&action=SwitchOnlineSupport&record={record_id}&cskhcs_type={support_type}"
        req = urllib.request.Request(url, headers=self.headers)
        with urllib.request.urlopen(req) as resp:
            return json.loads(resp.read().decode('utf-8'))
